# Cvora

An AI-powered CV builder and job matching platform.

## What it does

- Build a professional CV through a structured form or upload an existing PDF
- Generate a typeset single-page PDF via LaTeX
- Match your CV against live job listings from multiple sources
- Score jobs across skills, experience, location, and role relevance

## Stack

- **Backend**: FastAPI, PostgreSQL, Railway
- **Frontend**: Vanilla JS/HTML, Cloudflare Pages
- **AI**: OpenAI GPT-4o for CV extraction and matching
- **Storage**: Cloudflare R2
- **CV Generation**: LaTeX (pdflatex)
